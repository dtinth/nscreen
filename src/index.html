nscreen_

Show HTML on a remote screen through Nostr relays. End-to-end encrypted, no backend. New keys are made in this browser and are never sent anywhere.

Changing relays keeps the same keys.

1Display URL — open this on the screen

Open

Holds the screen's secret key. Anyone with this URL can read what the screen shows.

2Connection string — give this to the publisher

Can update the screen but can't read it. Anyone with this string can change what's shown.

Publish

// NSCREEN = the connection string above
const screen = new ScreenPublisher(process.env.NSCREEN)
await screen.publish({
  html: '<h1>Hello</h1>',
  css: 'h1 { color: tomato; view-transition-name: title }',
})
